# ⚔️ Turn-Based RPG Battle Arena

<div align="center">

![C++](https://img.shields.io/badge/C++-17-blue.svg)
![Raylib](https://img.shields.io/badge/Raylib-Game%20Framework-green.svg)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux-orange.svg)
![License](https://img.shields.io/badge/License-MIT-purple.svg)

A modern fantasy-inspired turn-based RPG battle game built with **C++** and **Raylib**.

Fight against AI opponents or challenge a friend in local multiplayer using unique character classes, powerful skills, status effects, particle effects, and strategic combat.

</div>

# 🎮 Features

## ⚔️ Warrior

**Role:** Balanced Fighter

### Skill: Shield Bash
- Deals bonus damage
- Stuns the enemy
- Strong offensive and defensive capabilities

### Stats
- High Attack
- Good Defense
- Balanced Health

---

## 🔮 Mage

**Role:** Magic Damage Dealer

### Skill: Fireball
- Massive magical damage
- Applies Poison effect
- Excellent energy pool

### Stats
- High Energy
- High Burst Damage
- Lower Defense

---

## 🏰 Tank

**Role:** Defensive Specialist

### Skill: Iron Wall
- Restores health
- Exceptional survivability
- Designed for long battles

### Stats
- Massive Health Pool
- Strong Defense
- Lower Damage Output

# 🏗️ OOP Concepts

## Encapsulation
Character data is protected within classes.

## Inheritance
Warrior, Mage, and Tank inherit from the Character base class.

## Polymorphism
Skills and attacks use virtual functions.

## Abstraction
Shared functionality is abstracted into a common character system.

# 🚀 Installation

## Windows (MinGW)

```bash
g++ main.cpp -o RPGBattle -lraylib -lopengl32 -lgdi32 -lwinmm
```

## Linux

```bash
g++ main.cpp -o RPGBattle -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
```

---

# ▶️ Running the Game

```bash
./RPGBattle
```

# 🎯 How to Play

1. Select a game mode.
2. Choose your character class.
3. Enter your player name.
4. Start the battle.
5. Use attacks and skills strategically.
6. Defeat your opponent.
7. View battle results.
